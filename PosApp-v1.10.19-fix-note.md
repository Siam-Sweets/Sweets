# PosApp v1.10.19 Fix Note

## Fixed

- Fixed new-store creation failing with `SQLite Error 19: UNIQUE constraint failed: Categories.StoreId, Categories.Name`.
- Made default category seeding idempotent against both database rows and already tracked local rows.
- Preserved the new store `SyncId` generated by the Store Details dialog.
- Prevented repeated Store save requests while a save is already running.

## Validation

- Added a regression case to `tests/PosApp.SyncRegression` that seeds a new store when a default category is already tracked locally and verifies each default category exists only once.
- Local compilation was not run in this workspace because the .NET SDK is not installed.
